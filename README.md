## Wichtig
Eine PWA benötigt HTTPS (oder localhost), damit der Service Worker funktioniert.

## Deployment
1. Repository über GitHub Pages, Cloudflare Pages oder Netlify veröffentlichen.
2. Die veröffentlichte HTTPS-Adresse auf dem Smartphone öffnen.
3. iPhone/iPad: Safari → Teilen → Zum Home-Bildschirm.
4. Android/Chrome: Menü → App installieren / Zum Startbildschirm hinzufügen.

Nach dem ersten erfolgreichen Laden kann die App über den Service Worker offline geöffnet werden.
