EnergieAufmaß PWA v2.11
=========================

Bereitstellung:
1. Den gesamten Inhalt dieses Ordners auf einen HTTPS-Webserver hochladen.
2. index.html über die HTTPS-Adresse öffnen.

iPhone / iPad:
Safari → Teilen → Zum Home-Bildschirm → Hinzufügen

Chrome (Laptop/Desktop):
Seite öffnen → App installieren

Hinweis:
Die vollständige PWA-Funktionalität einschließlich Service Worker funktioniert
über HTTPS oder localhost. Das direkte Öffnen der index.html aus dem Dateisystem
reicht dafür nicht aus.
